# Быстрый старт

Установите библиотеку, откройте сессию, задайте реестру три настоящих вопроса и корректно закройте
сессию. Сначала программа целиком, затем разбор каждой её строки.

## Установка

```xml
<dependency>
  <groupId>io.github.epptools</groupId>
  <artifactId>epptools-sdk</artifactId>
  <version>1.1.2</version>
</dependency>
```

Или Gradle, если сборка у вас на нём:

```groovy
implementation 'io.github.epptools:epptools-sdk:1.1.2'
```

Совсем без системы сборки: склонируйте репозиторий, привязавшись к тегу релиза, и соберите исходники
прямо в своё дерево — разрешать здесь нечего, сторонних зависимостей у библиотеки нет.

```bash
git clone --branch v1.1.2 https://github.com/epptools/java-sdk
javac --release 8 -d out $(find java-sdk/src/main/java -name '*.java')
```

## Что нужно до запуска

| Что | Откуда берётся |
|---|---|
| Хост и порт | Ваша учётная запись. Порт — `700`, если вам не сказали иное. |
| Ваш clID | Ваш идентификатор регистратора, например `EXAMPLE`. |
| Пароль | Выдаётся вместе с учётной записью, меняется через `login()` — см. [Сессию](session.md). |
| Сертификат CA реестра | Только там, где точка подключения предъявляет сертификат собственного закрытого CA реестра. Многие реестры предъявляют обычный сертификат, которому доверяют браузеры, и тогда настраивать нечего. Спросите, какой случай ваш, и `.pem`-связку, если она нужна. |
| Адрес отправления в белом списке | Многие реестры требуют, чтобы публичный IP вашего сервера был зарегистрирован для этого clID, иначе вход отклоняется кодом 2200. |

## Программа целиком

Сохраните её как `EppFirstRun.java`, подставьте значения сверху, скомпилируйте, положив
библиотеку на путь классов, и запустите.

```java
import com.epptools.sdk.Client;
import com.epptools.sdk.Config;
import com.epptools.sdk.Response;
import com.epptools.sdk.exception.EppException;

import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public final class EppFirstRun {

    public static void main(String[] args) {
        Config config = Config.builder("epp.registry.example", "EXAMPLE", "your-secret")
                .lang("en")                              // язык сообщений результата, если приветствие его перечисляет
                // .caFile("/etc/epp/registry-ca.pem")   // только для закрытого CA или самоподписанного сертификата
                .build();

        // Client реализует AutoCloseable, а close() разрывает соединение, поэтому try-with-resources
        // освобождает сокет на любом выходе из блока — включая пути, где до logout() дело не дошло.
        try (Client client = new Client(config)) {
            Response greeting = client.connect();
            System.out.println("server: " + or(greeting.value("svID"), "unnamed"));

            Response login = client.login();
            for (Map<String, String> event : login.securityEvents()) {
                System.err.println("login " + or(event.get("level"), "warning")
                        + " (" + or(event.get("type"), "custom") + "): " + event.get("text"));
            }

            Map<String, Object> feeQuery = new LinkedHashMap<String, Object>();
            feeQuery.put("create", 1);
            Response check = client.domain().check(Arrays.asList("example.com.ua"), feeQuery, null);

            if (Boolean.TRUE.equals(check.isAvailable("example.com.ua"))) {
                System.out.println("example.com.ua is available");
                System.out.println("  create, 1 year: "
                        + or(check.feeFor("example.com.ua", "create", 1), "not quoted")
                        + " " + or(text(check.fees().get("_currency")), ""));
            } else {
                System.out.println("example.com.ua is taken: "
                        + or(check.unavailableReason("example.com.ua"), "no reason given"));

                Response info = client.domain().info("example.com.ua");
                System.out.println("  sponsor: " + or(info.sponsor(), "-"));
                System.out.println("  expires: " + or(info.expiryDate(), "-"));
                System.out.println("  status:  " + join(info.statuses()));
                System.out.println("  ns:      " + join(info.nameservers()));
            }

            Response balance = client.balance();
            System.out.println("available credit: " + or(balance.availableCredit(), "-"));

            client.logout();
        } catch (EppException e) {
            System.err.println("EPP error: " + e.getMessage());
            System.exit(1);
        }
    }

    /** Значение, либо подстановка, когда реестр не прислал ничего. */
    private static String or(String value, String fallback) {
        return value == null || value.isEmpty() ? fallback : value;
    }

    /** Значение карты как строка, не падая на отсутствующем ключе. */
    private static String text(Object value) {
        return value == null ? null : value.toString();
    }

    /** Список через запятую, либо «-», когда ответ не нёс ни одного элемента. */
    private static String join(List<String> values) {
        return values.isEmpty() ? "-" : String.join(", ", values);
    }
}
```

Ожидаемый вывод на боевой учётной записи, когда имя зарегистрировано кем-то другим:

```
server: Registry EPP Server
example.com.ua is taken: In use
  sponsor: ACME
  expires: 2027-04-01T09:15:00Z
  status:  ok
  ns:      ns1.example.com.ua, ns2.example.com.ua
available credit: 12500.00
```

Ничто в этой программе ничего не меняет и ничего не стоит. `check`, `info` и запрос баланса — только
чтение, и именно поэтому они правильные первые команды: только их безопасно повторять вслепую.

## Строка за строкой

### `Config.builder(host, clid, password)`

Настройки соединения. `builder()` берёт три обязательных значения, а всем остальным полям
подставляет значения по умолчанию, поэтому для начала хватает трёх аргументов и `build()`:

- У **`host`**, **`clid`** и **`password`** нет осмысленных значений по умолчанию. Пустой `host` или
  пустой `clid` вызывает `ConfigException` уже из `build()`; пустой `password` — из `login()`, ещё до
  того, как на провод уйдёт хоть один байт.
- **`caFile`** нужен только там, где точка подключения предъявляет сертификат, выпущенный
  собственным закрытым CA реестра: такого CA нет ни в одном хранилище доверия, поэтому при проверке
  узла, оставленной в правильном значении по умолчанию, рукопожатие без него не состоится. Без
  `caFile` клиент доверяет собственному хранилищу JDK, и для сертификата, которому браузеры доверяют
  сами, это и есть верное поведение.
- **`port`** по умолчанию 700. `lang` по умолчанию `en`. Всё остальное разобрано поле за полем в
  [Сессии](session.md).

Не держите пароль в файле. Читайте его из окружения или из своего хранилища секретов; в примере он
выписан только для того, чтобы программа была полной.

### `new Client(config)`

Создание клиента ничего не открывает. Вы получаете объект; сокет будет дальше. Второй необязательный
аргумент принимает собственный транспорт, третий — логгер `Client.Logger`, см. [Сессию](session.md).

### `try (Client client = new Client(config))`

`Client` реализует `AutoCloseable`, а его `close()` вызывает `disconnect()`, поэтому
try-with-resources закрывает сокет, что бы ни случилось, в том числе на путях, где до `logout()` дело
не дошло. В Java нет деструктора, на который можно было бы положиться, поэтому это — или явный
`disconnect()` в `finally` — единственное, что освобождает сессию. Незакрытая сессия продолжает
занимать место в вашем лимите одновременных сессий, пока реестр не закроет её по тайм-ауту.

### `Response greeting = client.connect();`

Открывает TLS-сокет и читает незапрошенное `<greeting>` сервера — первое, что отправляет
EPP-сервер (RFC 5730). Приветствие перечисляет пространства имён объектов и расширений, которые
поддерживает этот сервер, а `login()` возвращает их обратно, поэтому сессию никогда не отклонят за
объявление сервиса, которого сервер не предлагает.

`connect()` возвращает приветствие как [`Response`](responses.md). `greeting.value("svID")`
достаёт из него имя сервера. Если первый кадр — не приветствие, `connect()` выбрасывает
`ConnectionException`, а не принимает пришедшее за перечень сервисов.

### `Response login = client.login();`

Отправляет `<login>` с вашими clID и паролем, версией протокола, языком и перечнем сервисов, взятым
из приветствия. Возвращает ответ на вход.

### Цикл `securityEvents()`

Там, где сервер предлагает расширение безопасности входа (RFC 8807), вход несёт небольшой блок,
идентифицирующий этот клиент, а сервер отвечает всем, что хочет видеть исправленным в этой сессии:
клиентский сертификат на подходе к истечению, устаревшая версия TLS, набор шифров, не являющийся
AEAD.

На здоровой сессии список пуст, поэтому считайте любую запись поводом действовать. Каждая запись
всегда несёт `text`; `type` и `level` присутствуют, если сервер их прислал, — отсюда подстановки в
примере: обращение к карте по ключу, которого в событии не было, даёт `null`. Самое частое событие —
сертификат, истекающий в ближайшие 30 дней; альтернатива узнать о нём здесь — узнать утром, когда
входы перестанут проходить.

### `client.domain().check(Arrays.asList("example.com.ua"), feeQuery, null)`

`domain()` возвращает обработчик доменных команд; `check()` отправляет `domain:check` (RFC 5731) и
возвращает ответ. Второй аргумент довозит вместе с ним запрос цены по RFC 8748, поэтому
один круг обмена отвечает сразу и на «свободно ли имя», и на «сколько оно будет стоить»; третий
называет валюту, а `null` берёт собственную валюту реестра. Вариант `check(names)` с одним
аргументом отправляет обычную команду вообще без запроса цены.

Запрос цены — это `Map<String, Object>`, потому что значением может быть либо один период, либо
список периодов: `feeQuery.put("renew", Arrays.asList(1, 2, 5))` спрашивает одну операцию сразу за
несколько периодов в одной команде.

Спросить цену бесплатно и ничего не меняет. Полная форма таблицы цен — в [Балансе](balance.md), там
же о том, как превратить то же расширение в **ограничение** суммы, которую с вас может списать
изменяющая команда.

### `check.isAvailable("example.com.ua")`

Возвращает `Boolean.TRUE`, `Boolean.FALSE` или `null`, если ответ ничего об этом имени не сказал.
Трёхзначный результат — в этом весь смысл: обращение к карте доступности по ключу, в котором вы
ошиблись, тоже даёт `null`, а эти два ответа не должны выглядеть одинаково в строке перед
регистрацией. Поэтому сравнение и написано как `Boolean.TRUE.equals(…)`, а не как `boolean`.

Сравнение не зависит от регистра, поэтому имя, набранное в смешанном регистре, всё равно совпадёт.

### `check.feeFor("example.com.ua", "create", 1)`

Названная цена одной операции за один период — точной десятичной **строкой** — или `null`, если
ответ такой цены не нёс. Никогда не приводите её к `double` перед арифметикой: используйте
`BigDecimal` или целые копейки. `fees().get("_currency")` — валюта, в которой указана вся котировка.

Суммы в этом руководстве иллюстративны и не являются тарифом реестра.

### `check.unavailableReason("example.com.ua")`

Собственная формулировка реестра о том, почему имя недоступно, — `In use`, `Reserved` — или `null`,
если имя свободно либо причина не указана.

### `client.domain().info("example.com.ua")`

`domain:info` возвращает полную запись имени, которое вам разрешено видеть. Программа отправляет её
только в ветке, где имя занято: `info` по несуществующему имени отклоняется кодом 2303, который
приходит как `ObjectDoesNotExistException`.

`sponsor()`, `expiryDate()`, `statuses()` и `nameservers()` — именованные аксессоры, поэтому вам
никогда не приходится лезть в карту по строке, которую пришлось угадывать. `expiryDate()` отдаёт
собственную строку реестра ровно в том виде, в каком она пришла. Все аксессоры перечислены в
[Ответах](responses.md).

`nameservers()` покрывает обе модели делегирования EPP — ссылку на объект хоста и имя со встроенными
glue-адресами, — поэтому список верен независимо от того, какую из них использует реестр.

### `client.balance()`

Баланс учётной записи регистратора, через собственное расширение баланса реестра.
`availableCredit()` — то, что вы ещё можете потратить: баланс плюс кредитная линия, если она есть,
снова точной десятичной строкой. См. [Баланс](balance.md).

### `client.logout();`

Завершает сессию. Сервер отвечает 1500 и закрывает связь. Сессия, брошенная без выхода, продолжает
занимать место в вашем лимите одновременных сессий, пока не истечёт по тайм-ауту, — поэтому выходите
по дороге наружу.

### `catch (EppException e)`

Любой сбой, который выбрасывает эта библиотека, наследуется от `EppException`, поэтому один `catch`
покрывает всё: неверный аргумент, сбой TLS, отказ реестра. Ловите подклассы там, где дальнейшие
действия различаются: 2104 значит остановить пакет и пополнить счёт, 2302 — выбрать другое имя.
Полная иерархия — в [Ошибках](errors.md).

Все они непроверяемые, поэтому написать этот `catch` вас никто не заставляет. Напишите его всё
равно: альтернатива — рабочий процесс регистрации, который умирает на 2303.
